
# Finanz.io



## One line summary
Our project is aimed to help beginners start their investing journey by making them learn regularly.
## Technology Stack
Framework:   
Languages used: TypeScript, React  
Database: MySQL  
ORM: Prisma  

## Project Overview
The main aim of this application is to address the challenge of acquiring the extensive knowledge required before starting one's investment journey. By breaking down the learning process into many short and engaging lessons, we help users achieve their goals and overcome the barriers that could discourage them from the actual investing.

Our project is split into three differents parts for various target groups. First section is called Daily Lessons. It is crucial for the young people who do not have enough time on daily basis. By building their streak, they are learning many important aspects of finances and investing in a relatively quick time.  
The second part is called Topics. It is especially made for people who are passionate about learning and love seeing their progress. This section is perfect for you if you want to customize your experience and learn the topics you want.
